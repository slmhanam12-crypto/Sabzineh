سبزینه — بسته آماده PWA

فایل‌ها:
- index.html: برنامه اصلی
- manifest.webmanifest: نام، آیکون و تنظیمات نصب
- service-worker.js: ذخیره فایل‌های ضروری برای بازشدن آفلاین
- icon-192.png و icon-512.png: آیکون برنامه

انتشار رایگان با GitHub Pages:
1. یک مخزن جدید در GitHub بسازید.
2. این پنج فایل را در ریشه مخزن بارگذاری کنید.
3. وارد Settings > Pages شوید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. شاخه main و پوشه /(root) را انتخاب و Save کنید.
6. پس از آماده شدن انتشار، لینک HTTPS نمایش داده می‌شود.

نکته: برای اولین بار باید برنامه را با اینترنت باز کنید تا فایل‌ها ذخیره شوند. سپس اجرای آفلاین را آزمایش کنید.
اندروید: Chrome > منو > Install app / Add to Home screen.
آیفون: Safari > Share > Add to Home Screen.

این بسته قابلیت نصب و پوسته آفلاین را اضافه می‌کند؛ اگر در آینده برنامه به API یا منابع خارجی وابسته شود، آن بخش‌ها ممکن است بدون اینترنت کار نکنند.
